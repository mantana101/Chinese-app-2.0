# Видеоуроки — готовые MP4

Девять коротких видео с русской озвучкой: четыре серии сюжетного фильма
«Первая поездка в Китай» (аэропорт → такси → отель → кафе) и пять учебных
уроков. Каждое видео — 1280×672, 24 кадра/с, H.264 + AAC, готово к показу
на любом устройстве и к загрузке на YouTube / VK / в соцсети.

Картинка — та же мультяшная сцена, что и в приложении (герои моргают,
говорящий открывает рот), титры показывают иероглифы, пиньинь и перевод.

## Как пересобрать

Нужны Node 18+, Python 3 с `fonttools` и `brotli`, статический `ffmpeg`.

```bash
# 1. шрифт с нужными иероглифами (Noto Sans SC, подмножество)
python3 tools/mkfont.py

# 2. кадры + звук + сборка
node tools/render-all.js
```

`tools/mkfont.py` собирает TTF из woff2-подмножеств `@fontsource/noto-sans-sc`:
resvg не умеет woff2, поэтому без этого шага иероглифы выходят квадратиками.

## Состав каталога

```
video/
  out/lesson-*.mp4     готовые видео (9 файлов, ~23 МБ всего)
  audio/n*.mp3         русская озвучка по урокам
  tools/data.js        выгружает сцены из index.html через jsdom
  tools/animate.js     оживляет кадр: рот говорящего, моргание, облака
  tools/frame.js       собирает кадр 1280×672: рисунок + карточка титров
  tools/render.js      кадры → PNG → ffmpeg → MP4
  tools/narr3.js       текст озвучки и веса сцен (источник правды для тайминга)
  tools/all.js         собирает все девять уроков
  tools/mkfont.py      TTF-подмножество Noto Sans SC для иероглифов
  tools/lessons.json   снимок сцен (для offline-пересборки)
```

Тайминг сцен считается по длине реплики: если переозвучить урок, начала
сцен пересчитаются автоматически — руками ничего править не нужно.
