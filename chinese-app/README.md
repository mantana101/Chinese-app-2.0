# 汉语学习 · Программа для изучения китайского языка

Полноценная система с **многопользовательским режимом**: ученики с профилями, учительская панель со сводкой по классу и выставлением оценок, адаптивный интерфейс для телефонов и компьютеров.

---

## Быстрый старт

### Вариант 1 — как владелец (учитель)

```bash
cd chinese-app
python3 server.py          # → http://0.0.0.0:8080
```

Откройте адрес в браузере. **Первый, кто зарегистрируется, автоматически становится владельцем** (роль `owner` — полный доступ). Регистрация: «Профиль» → «Войти или зарегистрироваться» → имя + пароль.

### Вариант 2 — ученик

Учитель присылает **код приглашения** (например `Q-T-E-9-6-7`) и ссылку на сервер. Ученик открывает ссылку → «Регистрация по коду» → вводит код, своё имя и пароль → сразу учится.

### Вариант 3 — без сервера

Откройте `index.html` двойным кликом. Программа работает полностью, прогресс хранится в браузере (но учитель его не увидит).

## Разделы программы

| Раздел | Описание |
|---|---|
| 🎯 **Уровень** | Диагностика из 50 вопросов → HSK-уровень и рекомендация по стартовому уроку |
| 📚 **Уроки** | 15 уроков в 4 модулях: словарь, грамматика, практика (4 типа заданий), домашка |

| ✍️ **Пропись** | Иероглифы мышью или пальцем в клетке 天字格, 26 базовых знаков |
| 📄 **Чтение** | 3 текста с пиньинь под каждым иероглифом и словарём к тексту |
| 💬 **Фразы** | 29 готовых реплик по ситуациям |
| 🔎 **Словарь** | Поиск по 313 словам курса |
| 👨‍🏫 **Класс** | *Только учитель:* сводка по ученикам, оценки, коды, экспорт CSV |
| 👤 **Профиль** | Данные аккаунта, статус синхронизации, вход/выход |

**В курсе:** 15 уроков · 284 слова · 122 задания · 3 текста · 26 иероглифов для прописи.

## Что видит учитель (раздел «Класс»)

- **Сводка по классу**: число учеников, средний балл, средняя точность, сколько активны сегодня.
- **Таблица учеников**: уроки пройдены, средний балл, точность, карточек, дней подряд, время последней активности.
- **Карточка ученика** (👁): разбор баллов по каждому уроку, лог ответов, история активности.
- **Выставление оценки** (✍️): оценка + комментарий учителя — сохраняется на сервере и видна ученику.
- **Коды-приглашения**: создание, копирование в один клик, отзыв неиспользованного кода.
- **Экспорт CSV** — для журнала или Excel.
- **Сброс прогресса** и **удаление ученика** (удалить владельца нельзя).

## Технические детали

- **Клиент**: один автономный файл `index.html` (~156 КБ), без внешних запросов.
- **Сервер**: `server.py` — только стандартная библиотека Python, без pip-зависимостей. SQLite (WAL), сессии в cookie `HttpOnly`, пароли через PBKDF2-SHA256 (200 000 раундов), ограничение попыток входа, CSRF-безопасные same-site cookie.
- **API**: `/api/auth/*`, `/api/progress`, `/api/class/*` (overview, students, grades, invites, export.csv).
- **Синхронизация**: прогресс сохраняется локально и автоматически отправляется на сервер (debounce 1.2 с). При обрыве связи работа продолжается локально.
- **Адаптив**: на телефоне — нижняя панель навигации, крупные кнопки, прокручиваемые таблицы; на компьютере — боковое меню.
- **Данные**: SQLite-файл `data/app.db` (создаётся автоматически). Резервная копия — просто скопируйте этот файл.

### Структура проекта

```
chinese-app/
├── server.py              # HTTP-сервер + API + SQLite
├── build.py               # сборка index.html из src/
├── index.html             # собранный клиент (автономный)
├── data/app.db            # база (создаётся сама)
└── src/
    ├── data.js            # контент курса: уроки, словарь, тексты, фразы
    ├── auth.js            # вход, синхронизация, учительская панель
    ├── app.js             # роутер, уроки, SRS, тоны, пропись
    ├── styles.css         # оформление
    └── index.template.html
```

После правки исходников: `python3 build.py`

## Как учиться (рекомендация)

1. Пройдите **«Уровень»** — 10 минут, получите стартовый урок.
2. 15–20 минут в день: один урок + повторение карточек. Карточки важнее нового материала.
3. Раз в неделю — **Тоны** и **Пропись**.
4. Домашку присылайте в чат — я проверю и разберу ошибки.
